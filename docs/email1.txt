Apologies for the delay. Here:
1. The scans are in high resolution (~0.5 to 1GB per image). I will ask permission first from all my co-authors if the high-res version can be shared (the original owner is National Museum of the Philippines). I will get back to you next week. Remind me if I forget.
2. MSE, batch size = 32
3. Depends. Stride size is 0.75 of the input size for 64 by 64, so the overlap is 25%. Stride size and overlap will depend on the input size. Smaller input size (32 by 32) does not necessarily need overlap since you can already generate thousands of training images here. For bigger input sizes (256 by 256), the overlap will be larger.
4. During reconstruction on the test sets, no need to implement overlap. Overlapping is done only on the training set to create a larger training dataset.
